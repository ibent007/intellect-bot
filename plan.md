# План и состояние intellect-bot

## Выполненные этапы

- [x] Единый диалог для обычных вопросов, программирования и перевода.
- [x] Меню «Новый чат», «Возможности» и «Настройки».
- [x] Выбор модели, креативности и часового пояса; отметка выбранного пояса.
- [x] История и настройки пользователя в PostgreSQL; очистка чата без удаления личных данных.
- [x] Личное расписание, просмотр и подтверждение изменений, проверка прошедших дат.
- [x] Напоминания с проверкой параметров, кнопками, защитой от повторов и изоляцией владельцев.
- [x] Серверный каталог MCP, права, входные и выходные схемы.
- [x] Общий JSON Schema-валидатор на клиенте и сервере.
- [x] Ограниченный агентный цикл с возвратом результатов MCP модели.
- [x] Погода, точный выбор места, сохранение списка уточнения и кэш публичных данных.
- [x] Справочные сведения и Telegram-ссылки из источников с указанием происхождения.
- [x] Общий протокол моделей, ограничение контекста и обработка квот.
- [x] Продолжение ответа по сохранённому результату чтения после ограничения API.
- [x] Безопасная команда `/why` и перевод времени в пользовательский пояс.
- [x] Моноширный код и перевод, читаемые таблицы и простые математические выражения.
- [x] Запуск приложения в Docker с отдельной PostgreSQL и постоянным volume.
- [x] Автономные тесты, проверки MCP и отдельный PostgreSQL-набор.
- [x] Сборка и автономные проверки; результаты описаны в `docs/VALIDATION.md`.
- [x] Ручная проверка основного функционала в Telegram подтверждена владельцем проекта.
- [x] Проведён эксперимент маршрутизации: baseline 12/12 и 7/9, revised 12/12 и 9/9.
- [x] Итоговая инструкция встроена в программу; отдельный текстовый файл для запуска не требуется.
- [x] Подготовлены анализ эксперимента и документация самостоятельного проекта.

## Дальнейшее развитие

- Отправка уведомлений в назначенное время.
- Новые инструменты и доверенные сценарии изменения данных.
- Независимый набор запросов и повторные измерения устойчивости маршрутизации.
- Расширение поддержки математических выражений и языков перевода.

Это направления развития, а не незавершённые обязательства текущей версии.
